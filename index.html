🔄 Selectable & Random Profiles on GitHub

View All-in-One Profile ➔

Because GitHub sanitizes Markdown and prevents client-side JavaScript execution for security reasons, here are the two native, bulletproof ways to have selectable or random profiles:

Option A: Native Selectable Dropdown Tabs (All-in-One)

Uses GitHub-supported native <details> and <summary> tags. Visitors to your GitHub profile can switch between Proposal 1 (Executive), Proposal 2 (Cyber Terminal), and Proposal 3 (Living Aurora) directly with a single click right on GitHub!

📁 File: README-all-in-one-selectable.md

Option B: Automated Random Rotation via GitHub Actions

An automated GitHub Actions workflow running on a schedule (e.g. daily at midnight UTC or every 12 hours) that randomly selects one of the 3 proposals and commits it to README.md. Your profile stays perpetually dynamic and surprising!

⚙️ Workflow: .github/workflows/rotate-profile.yml
